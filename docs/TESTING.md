# 테스트 체크리스트

실제 차량 운행 중 테스트하지 마세요. 데모 버튼은 정차 상태에서만 조작하세요.

## 자동 테스트

- 순수 Kotlin JUnit 52개: TaskParserTest 30 / RecommendationEngineTest 14 / VehicleGatewayTest 8.
- Room 계측 테스트: 4개. 실제 Android 환경에서 실행해야 합니다.
- 명령과 결과 위치는 README에 있습니다.

## 수동 검증

### 초기 실행·보존
- [ ] 새 설치에 정확히 샘플 업무 3개와 데모 경로가 표시된다.
- [ ] 각 샘플 업무에 데모 표시가 있고 실제 업무로 오인할 수 없다.
- [ ] 강제 종료 후 재실행해 업무와 이동 상태가 유지된다.
- [ ] 샘플을 모두 삭제해도 재실행 시 다시 생성되지 않는다.

### 입력·분석
- [ ] 예제 복합 문장이 우유/세탁소 업무 2개로 나뉘며 날짜가 맞다.
- [ ] 오늘/내일/모레, 이번 주/다음 주 금요일, ISO 날짜를 확인한다.
- [ ] 날짜 없는 문장은 마감 없음으로 남고 수동으로 날짜를 지정할 수 있다.
- [ ] 2026-02-30 같은 잘못된 날짜 때문에 앱이 종료되지 않는다.
- [ ] 빈 문장은 분석/저장할 수 없고 수동 등록은 이름 입력 후 저장할 수 있다.
- [ ] 분석 결과의 카테고리·장소·중요도·메모를 수정해 저장한다.
- [ ] 여러 결과 중 하나를 제외하면 나머지만 저장된다.
- [ ] 입력·분석 중 탭을 바꿨다 돌아와도 값이 유지된다.
- [ ] 화면 회전 후 입력/수정 중인 내용이 보존된다.
- [ ] 음성 인식 성공 결과가 입력창에 반영된다.
- [ ] 음성 인식 앱 없음·취소·권한 거부 시 텍스트 입력이 가능하다.

### 추천·상태 전환
- [ ] 3개 가상 목적지마다 카테고리에 맞는 샘플 장소와 고정 추가 시간이 보인다.
- [ ] 실제 장소와 다른 샘플 장소를 제안하면 명확한 경고가 보인다.
- [ ] 경유지 추가 후 상태가 진행 중이 되고 실제 등록 장소는 보존된다.
- [ ] 나중에 하기 후 현재 이동에서 카드가 사라지고 출발 때 다시 나타나지 않는다.
- [ ] 주행 시작 후 복잡한 등록·편집·완료 조작이 잠긴다.
- [ ] 도착 후 안내가 보이지만 업무는 자동 완료되지 않는다.
- [ ] 체크한 일만 완료되며 완료 기록과 오늘 완료 숫자가 갱신된다.
- [ ] 주차 때 남은 업무는 미완료로 남는다.
- [ ] 다음 이동 준비 후 READY 상태에서 미룬 일·미완료 일을 승인할 수 있다.
- [ ] 완료한 일은 다음 이동에서도 추천되지 않는다.
- [ ] 마감이 8일 이후이거나 기타 카테고리인 업무를 임의로 추천하지 않는다.

### 기록·편집
- [ ] 전체/완료/미완료 필터의 개수와 내용이 맞다.
- [ ] 카테고리와 등록일/마감일/완료일 필터를 조합하고 날짜를 지울 수 있다.
- [ ] 수정 후 재실행해도 새 값이 유지된다.
- [ ] 삭제에 확인창이 있으며 삭제 후 복구되지 않는다.
- [ ] 완료 취소 시 완료 시각이 지워지고 다시 활성 업무가 된다.

### UI·안전·오프라인
- [ ] API 26과 API 35 이상에서 세로 화면, 키보드, 시스템 바에 버튼이 가리지 않는다.
- [ ] 큰 글꼴(1.3배/2배)에서도 스크롤로 모든 내용을 확인한다.
- [ ] TalkBack에서 완료 버튼의 업무 이름과 탭/입력 필드가 읽힌다.
- [ ] 비행기 모드에서 텍스트 등록·추천·완료·기록이 작동한다.
- [ ] 음성은 기기 제공자에 따라 오프라인 동작이 다름을 안내한다.
- [ ] 앱이 닫혀 있을 때 알림이나 실제 위치 감지가 되지 않는 현재 한계를 확인한다.
