1. 위 APK 링크를 클릭해 파일을 다운로드합니다.
2. Android 스마트폰 또는 Pleos Connect v2.1.0 에뮬레이터에서 APK를 설치합니다. 필요 시 신뢰할 수 있는 설치 파일인지 확인한 후 설치 권한을 부여합니다.

4. `이동 추천`에서 데모 목적지를 선택하고 `주행 시작(데모)`을 눌러 추천 업무 및 경유지 추가 **시뮬레이션**을 확인합니다. 이 기능은 실제 내비게이션에 반영되지 않습니다.

## 1. 프로젝트 소개

**RouteMate**는 운전자가 해야 할 일을 기억하고,  
차량의 이동 상황을 활용해 **적절한 시점에 실행하도록 도와주는 AI 기반 차량 생활 업무 관리 앱**입니다.

운전자는 이동 중 다음과 같은 생활 업무를 자주 떠올립니다.

- 퇴근길에 우유 사기
- 세탁소 들르기
- 택배 보내기
- 약속 전 필요한 물건 챙기기

하지만 실제로는 운전 중 기록하기 어렵고,  
이동하면서 처리할 수 있는 일도 놓치기 쉽습니다.

RouteMate는 단순히 할 일을 저장하는 앱이 아니라,

- **해야 할 일을 기억하고**
- **현재 이동 상황에서 실행 가능한 기회를 찾고**
- **실제 완료 여부까지 관리하는 것**

을 목표로 합니다.

---

## 2. 공모전 기획 의도

본 프로젝트는 **현대자동차그룹 Pleos 차량용 앱 개발 공모전**을 위해 기획되었습니다.

### 우리가 해결하고자 하는 문제
기존 메모 앱이나 일정 앱은 할 일을 저장하고 알림을 제공하지만,  
**운전자의 실제 이동 상황과 연결해 실행 기회를 제안하고 완료까지 이어주는 경험**은 부족합니다.

### RouteMate의 핵심 제안
RouteMate는 차량을 단순한 이동 수단이 아니라,  
**일상생활의 업무를 실행하는 기회의 공간**으로 확장합니다.

---

## 3. 핵심 가치

### 1) 기억 부담 감소
운전 중 떠오른 할 일을 음성 또는 텍스트로 빠르게 기록할 수 있습니다.

### 2) 차량 이동 정보의 실용적 활용
현재 이동 상황, 경로, 목적지, 마감기한을 고려해  
**지금 처리할 수 있는 업무**를 추천합니다.

### 3) 업무 완료까지 연결
한 번 알림을 주고 끝나는 것이 아니라,  
미완료된 업무를 다음 이동 기회에 다시 반영합니다.

## 4. 기존 서비스와의 차별성

| 구분 | 일반 메모/일정 앱 | RouteMate |
|---|---|---|
| 할 일 저장 | 가능 | 가능 |
| 알림 제공 | 가능 | 가능 |
| 이동 경로와 연결 | 제한적 | 가능 |
| 현재 이동 중 처리 가능한 업무 추천 | 제한적 | 핵심 기능 |
| 미완료 업무 재추천 | 단순 재알림 수준 | 다음 이동 상황에 맞춰 재계획 |
| 차량용 서비스 확장성 | 낮음 | 높음 |

**RouteMate의 차별점은**  
“할 일을 저장하는 것”이 아니라  
**‘이동 중 실행 가능한 순간’을 찾아주는 것**입니다.

## 5. 주요 기능

### 01. Smart Task Registration  
**자연어 기반 할 일 등록 (현재 규칙 기반)**

사용자가 자연어로 할 일을 입력하면 현재는 규칙 기반 파서로 업무를 분석해 구조화합니다. 외부 LLM 분석은 향후 계획입니다.

**예시 입력**
> 오늘 우유 사고, 이번 주 금요일까지 세탁소에서 옷 찾아야 해.

**분석 예시**
- 우유 구매 / 마감: 오늘
- 세탁소 방문 / 마감: 금요일

저장 항목:
- 할 일 이름
- 카테고리
- 마감 날짜
- 관련 장소
- 중요도
- 완료 여부
- 메모

---

### 02. Route-based Task Recommendation  
**이동 상황 기반 업무 추천**

현재는 **샘플 경로 및 장소 데이터**와 등록된 업무를 연결해 실행 가능한 할 일을 추천합니다.

**예시**
> 현재 이동 경로 근처에 마트가 있어요.  
> 오늘 우유 구매를 처리해 보는 건 어떨까요?

추천 카드에는 다음 정보가 표시됩니다.
- 추천 업무
- 관련 장소
- 마감기한
- 상태
- 경유지 추가
- 나중에 하기

---

### 03. Driving Context Reminder  
**주행 상황별 알림**

현재는 **가상 주행 이벤트**에 맞춰 필요한 업무를 상기시킵니다.

- 주행 시작: 오늘 처리할 업무 확인
- 목적지 도착: 관련 업무 리마인드
- 주차 완료: 하차 전 해야 할 일 확인

---

### 04. Unfinished Task Recovery  
**미완료 업무 재관리**

특정 장소에 도착했다고 해서 자동 완료되지 않습니다.  
사용자가 직접 완료를 확인해야 하며,  
완료하지 못한 업무는 다음 이동 상황에서 다시 제안됩니다.

**예시**
> 어제 세탁소 방문을 완료하지 못했어요.  
> 오늘 이동할 때 다시 확인할까요?

---

### 05. Dashboard & History  
**업무 현황 및 기록 관리**

- 오늘의 할 일 요약
- 완료 / 미완료 현황
- 마감 임박 업무
- 추천 업무 확인
- 업무 수정 / 삭제
- 기록 조회 및 필터

## 8. 현재 개발 현황 (Android MVP)

RouteMate는 **Pleos Connect v2.1.0 에뮬레이터에서 실행되는 Android MVP**입니다. 스마트폰용 UI와 차량용 넓은 화면 UI를 화면 크기에 따라 구분해 표시합니다.

### 구현 완료

- 할 일 등록·조회·수정·삭제 및 완료/미완료 관리
- **규칙 기반** 자연어 문장 분석과 업무 정보 추출
- **샘플 경로·장소 데이터** 기반 업무 추천
- 주행 시작·목적지 도착·주차 완료 **이벤트 시뮬레이션**
- 미완료 업무의 다음 이동 시 재추천
- Room Database 기반 기기 내 로컬 저장
- Pleos Connect 차량용 가로 UI: 홈 2열 대시보드, 확대된 글씨·아이콘·버튼
- Pleos Connect v2.1.0 에뮬레이터에서 앱 실행 및 UI 표시 확인

### 현재 미구현·제한 사항

- **NaviHelper SDK 미연동:** '경유지 추가'는 실제 내비게이션 경유지 등록이 아닌 데모 동작
- **Vehicle / FusedLocation SDK 미연동:** 실제 차량 상태·현재 위치 사용 안 함
- **실제 지도·POI·영업시간·경로 API 미연동:** 샘플 장소 및 시간 사용
- **스마트폰–차량 간 동기화 미구현:** 현재 Room 데이터는 설치된 기기별로 저장
- **주행 중 간편 할 일 패널 미구현:** 내비게이션 옆 분할 화면 표시 및 운전 상태에 따른 조작 제한은 향후 검토
- **외부 LLM 미연동:** 규칙 기반 문장 분석 사용

## 9. 향후 개발 로드맵

### Phase 1 — Pleos 내비게이션 연동

**NaviHelper SDK**를 이용해 목적지·경로 정보를 조회하고, 사용자가 승인한 추천 장소를 실제 내비게이션 **경유지로 등록**하는 기능을 개발할 계획입니다. SDK 권한과 요청 결과를 확인하고, 실패 시 앱에서 안내하도록 구현할 예정입니다.

### Phase 2 — 스마트폰 ↔ 차량 할 일 동기화

운전 전에는 스마트폰에서 할 일을 등록·수정하고, 차량에 탑승하면 같은 목록을 확인하며, 차량에서 완료한 업무 결과가 스마트폰에 반영되는 **연속적인 사용 경험**을 목표로 합니다.

- 스마트폰에서 할 일 작성·마감일 설정 → 차량 앱에서 동기화된 목록 확인
- 차량의 추천 업무 처리·완료 상태 → 스마트폰에도 반영
- 실시간 연결이 없을 때는 로컬에 저장하고 연결 회복 후 동기화
- 본인 계정 인증, 데이터 암호화, 동기화 충돌 처리 및 개인정보 보호 설계

**현재는 동기화 서버·계정·차량–스마트폰 연결이 구현되지 않았습니다.** 연동 방식(계정 기반 클라우드 동기화 등)은 개발 과정에서 확정할 예정입니다.

### Phase 3 — 주행 중 간편 할 일 패널 (Navigation Side Panel)

차량 주행 중에는 내비게이션을 주 화면으로 유지하고, 화면 분할이 허용되는 환경에서 **RouteMate의 간편 할 일 목록을 옆에 표시하는 보조 패널**을 개발할 계획입니다.

- **출발 전·주차 중:** 할 일 등록·수정, 추천 경유지 확인, 완료 상태 관리 등 전체 기능 제공
- **주행 중:** 현재 경로와 관련된 **우선순위 높은 할 일 1~2개**만 간결하게 표시하고, 긴 문장·세부 편집·스크롤 등 운전 집중을 방해하는 조작 최소화
- **도착·안전한 정차 후:** 실제 업무 완료 여부를 확인하고 미완료 항목을 다음 이동에서 재추천
- **안전·호환성 검증:** Pleos Connect의 멀티윈도우 지원 여부와 주행 중 사용 제한(Distraction Optimization 등), 화면 크기별 표시 정책을 확인한 뒤 구현 범위 결정

> 현재 구현된 **차량용 2열 홈 대시보드**와는 별개의 기능입니다. 실제 내비게이션과 RouteMate를 나란히 표시하는 분할 화면 및 주행 중 패널은 아직 구현하지 않았습니다.

### Phase 4 — 실제 차량 상태·위치 기반 추천

**Vehicle SDK / FusedLocation SDK**를 연동해 실제 이동 상태와 위치를 활용하고, 주행 중 안전한 알림 시점을 판단하는 기능을 개발할 예정입니다.

### Phase 5 — 차량 정보 기반 AI 맞춤형 업무 추천

Vehicle SDK와 Location SDK를 활용해 실제 차량의 주행·도착·주차 상태 및 위치 정보를 연동하고, 상황에 맞는 생활 업무를 추천할 계획입니다.
또한 SpeechToText / TextToSpeech와 외부 LLM을 적용해 음성 업무 등록·안내 및 자연어 분석을 고도화하고, 지도·장소 API를 통해 주변 장소의 영업시간과 추가 이동시간을 고려한 개인화 추천으로 확장할 예정입니다.
주행 중에는 복잡한 조작을 최소화하고, 간결한 음성 안내와 핵심 정보 중심의 화면을 제공하는 방향으로 개발할 계획입니다.

> **개발 상태 요약:** Pleos Connect 실행 및 차량용 UI는 확인했으며, 실제 내비게이션 연동, 스마트폰 동기화, 주행 중 간편 할 일 패널은 **향후 개발 계획**입니다.
