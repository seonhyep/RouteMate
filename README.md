---

## 1. 프로젝트 소개

**RouteMate**는 운전자가 해야 할 일을 기억하고,  
차량의 이동 상황을 활용해 **적절한 시점에 실행하도록 도와주는 AI 기반 차량 생활 업무 관리 앱**입니다.

운전자는 이동 중 다음과 같은 생활 업무를 자주 떠올립니다.

- 퇴근길에 우유 사기
- 세탁소 들르기
- 택배 보내기
- 약속 전 필요한 물건 챙기기

하지만 실제로는 운전 중 기록하기 어렵고,  
이동하면서 처리할 수 있는 일도 놓치기 쉽습니다.

RouteMate는 단순히 할 일을 저장하는 앱이 아니라,

- **해야 할 일을 기억하고**
- **현재 이동 상황에서 실행 가능한 기회를 찾고**
- **실제 완료 여부까지 관리하는 것**

을 목표로 합니다.

---

## 2. 공모전 기획 의도

본 프로젝트는 **현대자동차그룹 Pleos 차량용 앱 개발 공모전**을 위해 기획되었습니다.

### 우리가 해결하고자 하는 문제
기존 메모 앱이나 일정 앱은 할 일을 저장하고 알림을 제공하지만,  
**운전자의 실제 이동 상황과 연결해 실행 기회를 제안하고 완료까지 이어주는 경험**은 부족합니다.

### RouteMate의 핵심 제안
RouteMate는 차량을 단순한 이동 수단이 아니라,  
**일상생활의 업무를 실행하는 기회의 공간**으로 확장합니다.

---

## 3. 핵심 가치

### 1) 기억 부담 감소
운전 중 떠오른 할 일을 음성 또는 텍스트로 빠르게 기록할 수 있습니다.

### 2) 차량 이동 정보의 실용적 활용
현재 이동 상황, 경로, 목적지, 마감기한을 고려해  
**지금 처리할 수 있는 업무**를 추천합니다.

### 3) 업무 완료까지 연결
한 번 알림을 주고 끝나는 것이 아니라,  
미완료된 업무를 다음 이동 기회에 다시 반영합니다.

---

## 4. 기존 서비스와의 차별성

| 구분 | 일반 메모/일정 앱 | RouteMate |
|---|---|---|
| 할 일 저장 | 가능 | 가능 |
| 알림 제공 | 가능 | 가능 |
| 이동 경로와 연결 | 제한적 | 가능 |
| 현재 이동 중 처리 가능한 업무 추천 | 제한적 | 핵심 기능 |
| 미완료 업무 재추천 | 단순 재알림 수준 | 다음 이동 상황에 맞춰 재계획 |
| 차량용 서비스 확장성 | 낮음 | 높음 |

**RouteMate의 차별점은**  
“할 일을 저장하는 것”이 아니라  
**‘이동 중 실행 가능한 순간’을 찾아주는 것**입니다.

---

## 5. 주요 기능

### 01. Smart Task Registration  
**AI 기반 할 일 등록**

사용자가 자연어로 할 일을 입력하면 업무를 분석해 구조화합니다.

**예시 입력**
> 오늘 우유 사고, 이번 주 금요일까지 세탁소에서 옷 찾아야 해.

**분석 예시**
- 우유 구매 / 마감: 오늘
- 세탁소 방문 / 마감: 금요일

저장 항목:
- 할 일 이름
- 카테고리
- 마감 날짜
- 관련 장소
- 중요도
- 완료 여부
- 메모

---

### 02. Route-based Task Recommendation  
**이동 상황 기반 업무 추천**

현재 이동 상황과 업무를 연결해  
실행 가능한 할 일을 추천합니다.

**예시**
> 현재 이동 경로 근처에 마트가 있어요.  
> 오늘 우유 구매를 처리해 보는 건 어떨까요?

추천 카드에는 다음 정보가 표시됩니다.
- 추천 업무
- 관련 장소
- 마감기한
- 상태
- 경유지 추가
- 나중에 하기

---

### 03. Driving Context Reminder  
**주행 상황별 알림**

차량의 상태 변화에 맞춰 필요한 업무를 상기시킵니다.

- 주행 시작: 오늘 처리할 업무 확인
- 목적지 도착: 관련 업무 리마인드
- 주차 완료: 하차 전 해야 할 일 확인

---

### 04. Unfinished Task Recovery  
**미완료 업무 재관리**

특정 장소에 도착했다고 해서 자동 완료되지 않습니다.  
사용자가 직접 완료를 확인해야 하며,  
완료하지 못한 업무는 다음 이동 상황에서 다시 제안됩니다.

**예시**
> 어제 세탁소 방문을 완료하지 못했어요.  
> 오늘 이동할 때 다시 확인할까요?

---

### 05. Dashboard & History  
**업무 현황 및 기록 관리**

- 오늘의 할 일 요약
- 완료 / 미완료 현황
- 마감 임박 업무
- 추천 업무 확인
- 업무 수정 / 삭제
- 기록 조회 및 필터

## 8. 현재 구현 범위 (MVP)

현재 저장소는 **Android MVP 버전**입니다.

### 구현 완료
- 할 일 등록 / 조회 / 수정 / 삭제
- 규칙 기반 문장 분석
- 데모 이동 상황 선택
- 이동 기반 할 일 추천
- 주행 시작 / 목적지 도착 / 주차 완료 이벤트 시뮬레이션
- 완료 / 미완료 상태 관리
- 미완료 업무 재추천
- Room 기반 로컬 저장

### 현재 제한 사항
- 실제 Pleos SDK 미연동
- 실제 차량 데이터 미연동
- 실제 지도 / 경로 API 미연동
- 외부 LLM 미연동
- 데모 장소 / 이동시간 기반 시뮬레이션

> 본 프로젝트는 차량용 서비스로 확장하기 위한 **첫 번째 Android MVP**입니다.

## 9. Pleos 확장 방향

RouteMate는 향후 Pleos 환경에서 다음과 같이 확장될 수 있습니다.

- **Vehicle SDK**  
  차량 상태 기반 실행 시점 판단

- **NaviHelper SDK**  
  경로 및 목적지 기반 업무 추천

- **FusedLocation SDK**  
  위치 기반 실행 기회 탐색

- **SpeechToText SDK**  
  운전 중 음성 업무 등록

- **TextToSpeech SDK**  
  주행 중 안전한 음성 안내

즉, RouteMate는 단순 모바일 앱이 아니라  
**차량 데이터와 이동 맥락을 적극 활용할 수 있는 차량 특화형 서비스 구조**를 갖고 있습니다.

## 10. 데모 시나리오

### Step 1. 할 일 등록
> 오늘 우유를 사고, 금요일까지 세탁소에서 옷 찾아야 해.

### Step 2. 이동 시작
사용자가 데모 주행 이벤트를 시작합니다.

### Step 3. 업무 추천
앱이 현재 이동 상황에서 처리 가능한 업무를 추천합니다.

### Step 4. 완료 여부 반영
우유 구매는 완료 처리, 세탁소 방문은 미완료 처리합니다.

### Step 5. 다음 이동에서 재추천
다음 이동 시 미완료 업무가 다시 추천됩니다.
